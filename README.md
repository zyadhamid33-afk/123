# CrashWatch Ziad

Android prototype for locally recording crash-game multipliers and calculating descriptive statistics.

## Build
GitHub Actions builds a debug APK on every push to main. Download it from Actions → latest successful run → Artifacts.

## Current limitations
- This first build is a local statistics prototype. It does not connect to 1xBet or any private game server.
- Results are entered manually; automatic screen reading is not implemented in this build.
- Statistics describe recorded history only and do not predict or guarantee future outcomes.
- Do not enter betting-account passwords, tokens, or private API keys.
